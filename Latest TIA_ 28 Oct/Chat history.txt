There are two separate codes, so let me briefly explain what each one does.
The 'baseline_measuerment' code is for measuring the baseline. Since we're integrating the current to calculate the charge, having an accurate 0 V reference is important. When using the TIA in an electrolyte environment, the TIA output might not be exactly 0 V even when 0 V is applied. So this code measures that offset.
The 'TIA_deposition_1pixel' code is for the actual deposition process. It follows the mechanism I explained earlier. The part highlighted in the attached image is where you set the baseline. You just need to enter the value measured from the first code and then run the deposition code.
Ideally, it would be best to measure the baseline for each pixel since it could vary slightly between pixels. But I think measuring it for the first pixel and using the same baseline for the others shouldn't introduce a significant error.
Also, feel free to modify the deposition code to fit your setup! I don't think there should be any major issues with that.
